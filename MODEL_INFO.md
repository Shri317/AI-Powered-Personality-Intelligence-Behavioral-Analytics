# Model Information

The repository contains the supplied trained artifacts:

- `model.pkl`: scikit-learn Logistic Regression classifier
- `scaler.pkl`: scikit-learn StandardScaler
- Input dimensionality: 26 features
- Model classes exposed by the classifier: `0, 1, 2`

The original training dataset and training notebook/code were not included in the supplied files, so training accuracy, test accuracy, confusion matrix, dataset size, and feature-generation methodology are intentionally not claimed here.

The application itself performs scaling and prediction and visualizes the returned class probabilities.
